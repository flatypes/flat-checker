# Evaluation of OSTRICH

## 1. Download the artifact

Download the artifact from <https://doi.org/10.1145/3291630> (about 1.2 GB). (This needs to be done manually due to restrictions of the ACM Digital Library.)

## 2. Unzip the artifact

Unzip the artifact into a subdirectory of the current directory named `ostrich-popl19-artifact`.

```shell
unzip popl19main-p235-p3290362-artifact-accepted-archive.zip -d ostrich-popl19-artifact
```

## 3. Run the evaluation

```shell
./run_eval.sh
```
